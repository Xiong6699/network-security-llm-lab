# 标准输入字段

模型输入与内部评估元数据分离。直接审计实例见 llm_inputs/；完整来源与原始路径见相同 ID 的 sample_metadata/，不整包提供给模型。

| 字段 | 内容 |
| --- | --- |
| 样本 ID | 稳定唯一编号，不暗示漏洞结论 |
| 来源引用 | 使用 ID 查询内部来源及授权，不透露靶场难度名称 |
| 语言与环境 | 语言、已知运行约束；未知版本明确填写未知 |
| 审计关注类型 | 范围，例如 SQL 注入，不写“已存在 SQL 注入” |
| 入口与参数 | 请求方式、参数及触发条件 |
| 调用与输出关系 | 输入到危险操作与观察点的路径 |
| 依赖 | 外部文件、渲染函数、认证及数据库要求 |
| 已知限制 | 未提供内容、未知条件、需部署适配事项 |
| 代码 | 保持语法，无数字行号前缀 |
| 行号约定 | 从 1 开始的标准化代码行号与人工映射方式 |
| 期望输出 | 结论、位置、成立条件、证据不足与补充需求 |

模板不包含人工候选标签、POC 答案、原始 difficulty 名称，也不是工作包 2 的完整四段式 Prompt。组 2 应添加角色、判定规则、输出格式和 POC 约束，并保存实际使用的 Prompt 全文。

## 多文件流程输入

v2 增加父样本ID、输入包ID、关联片段ID、完整依赖关系与运行条件。每个代码块按局部1起始行号定位，元数据保存全部源文件映射。模型先给出包内证据，再综合该父样本所有包判定；共享片段只作为上下文，不重复计入漏洞数量。原代码中用于运行配置判断的实际等级字符串保留，但教学答案提示不作为审计输入。
