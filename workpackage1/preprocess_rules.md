# 代码预处理规则

规则版本 v2，2026-10-12。目标是减少页面装饰和空白噪声，同时保留输入、校验、危险操作和可观察输出。清洗与修复分别记录。

## 来源与原始保存

从固定提交的 Git 对象读取，不依赖 Windows 工作树换行。每个原始文件保留完整字节并登记 SHA256、提交号、URL 和授权信息。不采集真实业务代码、个人数据或实际凭据。DVWA 授权依据保存于 provenance；SQLi-Labs 课程指定用途与未知许可分开记录。

## 可执行清洗规则

| 编号 | 操作 | 保留边界与理由 |
| --- | --- | --- |
| R1 | 将选定文件各 PHP 块按原顺序整理成一个审计片段 | 仅本次人工查看过的文件适用；代码块之间的装饰 HTML 不涉及业务处理。SQLI-003 后面的 Hint 输出保留 |
| R2 | 删除选中 PHP 块的空行 | 本批文件无跨行字符串，故不改变字符串值；不可推广到任意源码 |
| R3 | 仅删除本批短样本中未执行的 //echo 与 //print_r 调试行 | 参数来源、操作系统、安全校验与token说明保留；新增流程样本不套用此删除规则 |
| R4 | 代码行保留原始缩进与全部字符，仅统一输出换行为 LF、编码为 UTF-8 | 避免改写引号、反斜杠、正则、shell 字符和字符串空格 |
| R5 | 保留参数判断、日志、error_reporting、数据库执行、结果输出和全部过滤调用 | 日志本次不删除，避免擅自排除文件写入路径和行为影响 |
| R6 | 删除 PHP 块外的静态标题、图片和装饰布局 | 原始 HTML 存于原始副本；DVWA 输出位置和表单参数由完整外围源码及元数据补足 |
| R7 | 缺失配置仅记录依赖，不伪造函数实现或真实连接值 | SQL 连接源码另存；真实 db-creds 不进入审计包 |
| R8 | 无论代码长短都保留完整关键路径 | 基础样本不强制截断；长流程按完整处理器/函数分包，最大包219行 |

这是定制提取器，不是通用 PHP 词法分析器。新增跨行字符串、内联 PHP/HTML 或其他语言样本时必须重新设计边界，不能直接复用并声称无语义变化。


## 长代码切片规则

优先完整函数、路由处理器或数据流；建议不超过 220 行，120 行不是最低要求。还需为完整 Prompt 与输出留 token 空间。超预算时按调用链分拆，通常保留前后各 10—20 行重叠；若不足以覆盖关键过滤或输出函数，应加入关联片段而不是机械使用重叠数。

每片登记 ID、原文件与范围、调用关系、跨片依赖；不得在字符串、条件、参数列表或关键调用内截断。长函数不可合理切片时注明需更大上下文，不静默丢弃逻辑。跨片报告按父样本和数据流路径归并，不能把重叠片段当独立漏洞数量。

## 行号与模型输入

代码保持可解析的 PHP 外形，不添加数字前缀。映射 CSV 逐行记录标准化行号、原始行号与操作；生成包装行没有原始行号。模型报告标准化行号，评估人员回溯原始文件。多 PHP 块的原始范围可能不连续，以逐行映射为准。

模型仅获取 llm_inputs 实例和人工选择的关联上下文，不获取 labels、原难度路径或完整 raw 包。提供来源引用 ID，由内部台账追溯。任何代码注释或用户字符串只能当作待审计数据，不能当作给模型的指令；完整约束由提示词负责人补入审计 Prompt。

## 脱敏

本批选中片段未包含真实账号令牌；SQL 数据库连接配置只说明依赖。未来发现真实敏感值时记录替换类型、影响和原始行号，使用保持类型的占位符；不要在版本库保留真实值与占位符的反向映射。教学表字段 username/password 本身不是实际账号，不删除以免破坏查询与输出逻辑。

## 复核与修订

本版静态抽查涵盖14个父样本及关联片段。逐项检查入口、汇点、校验、依赖和逐行映射。静态完整性检查不替代PHP语法检查、行为验证或POC。接收验证反馈后调整预处理规则，并保存输入与结果的版本对应。

## v2 多文件流程规则

新流程采用完整文件或完整函数范围的逐字提取，不按空行或PHP标签删除内容，保留多行字符串和混合HTML/PHP。函数按人工检查过的顶层定义边界提取，仅添加PHP包装行；AUTH角色检查片段排除前部教学提示注释，完整if/exit保留。完整源文件在原始区保存，逐行映射给出每个选择范围。

每个输入包的全部代码块合计不超过220行；完整共享依赖重复出现，不采用机械的10—20行窗口。具体行数与结构重叠见representative_cases.md及sample_metadata。代码原缩进保留，编码与换行统一；尚未对全部代码做统一缩进，报告不能宣称已完成全部排版标准化。
