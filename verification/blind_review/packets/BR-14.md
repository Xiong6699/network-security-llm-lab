# 独立盲评包 BR-14

你是第二位独立复核人。你只看到一次本地授权靶场运行的脱敏证据，不知道原复核人的结论，也不知道样本的正式标签。不要读取仓库中的其它文件，不要根据运行编号、样本编号或公开靶场记忆猜测答案；只按下列成功标准逐条核对证据。

## 本次条件

- 路径：`vulnerabilities/exec/index.php:ip`
- 条件：`env=dvwa-wsl-01|role=admin|security=impossible|object=none|state=initialized`
- 成功标准：
  1. The normal loopback ping produces the expected command output.
  2. The token-protected request reaches the numeric-octet validation.
  3. A payload containing a command separator is rejected as an invalid IP and no marker is executed.
  4. A five-octet input is also rejected; the negative result is limited to this four-octet gate.
- 已知限制：
  - Only the impossible exec source path and this Linux container are covered.
  - The payload only prints a fixed marker; it does not read files or open a connection.
  - The negative result applies to the four-octet is_numeric gate; IP-format weaknesses are recorded separately, not as command injection.
