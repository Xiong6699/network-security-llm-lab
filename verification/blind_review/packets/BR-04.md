## 本次条件

- 路径：`vulnerabilities/xss_r/index.php:name`
- 条件：`env=dvwa-wsl-01|role=admin|security=medium|object=none|state=initialized`
- 成功标准：
  1. The page returns an authenticated response and reflects the control text.
  2. The payload reaches the final HTML position without an applicable output filter.
  3. Headless Chrome sets the JS marker in the page context, proving execution, not just reflection.
- 已知限制：
  - Only the medium xss_r path is covered in one desktop Chrome version.
  - The marker is harmless and creates no network request.
